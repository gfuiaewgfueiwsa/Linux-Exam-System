# 考试系统简化版

学生端填名字进入、左侧题目栏、右侧一个命令输入框 —— **没有虚拟机、没有镜像、没有 SSH**，
命令在 Python 进程内的 Linux 沙箱里执行，回车即判分，打对一个亮一个，**不限顺序**。
教师端沿用完整版控制台（同一个 `teacher.html`，接口逐字段对齐）。

本目录是与 `D:\KSXT` 主项目**完全独立的新项目**：不 import 主项目 `app/`，
不读写主项目 `data/`，两边改代码互不影响。

## 二、启动

| 方式 | 命令 |
| --- | --- |
| 双击 | `启动简化版.bat` |
| 命令行（开公网隧道） | `python start_all.py` |
| 命令行（仅本机，不开隧道） | `python start_all.py --local` |
| 只起后端 | `python app/server.py`（默认 8100）/ `python app/server.py 8100` |

启动后可访问：

- 学生端本机 `http://localhost:8100`
- 学生端公网：3 条备用 `https://xxx.trycloudflare.com`，同时打印在窗口并写入 **`公网地址.txt`**
- 教师控制台 `http://localhost:8101` —— **只监听 127.0.0.1，不进隧道**，免登录
  （学生端 8100 上访问 `/teacher` 会明确返回 404「教师控制台仅在本机 8101 端口开放」）

关窗口即整组退出：`start_all.py` 用 Job Object 托管子进程，主进程被结束时会一并终止
`cloudflared`，不留残留隧道占端口；下次启动还会清掉端口空闲时的僵尸 `cloudflared.exe`。

## 三、玩法（学生端）

1. 打开公网地址 → 只有「填姓名 + 开始考试」一屏（卡片上会显示考场状态：未开放 / 距开考 / 进行中 / 已结束）。
2. 左侧是 **37 题平铺列表**，只有题号、题目与要求（不分幕、不分组）；右侧是输出滚动区 + 单个命令输入框。
3. 命令**随便什么顺序打**，回车后哪道题的判据被满足，哪道题就变绿点亮并计入分数——界面上没有浮提示、
   没有播报，只有题单状态与顶栏数字在变。
4. 交互命令按真实终端手感走：`sudo su` 后单独一行输密码、`vim` 里 `i` / 正文 / `Esc` / `:wq`、
   `less` 里空格翻页 `q` 退出。这些续行只喂给沙箱，**不算命令、不进日志**。
5. 顶部实时显示 已完成 / 分数 / 剩余时间 / 闸门状态，可交卷。考试期间强制全屏：退出全屏会扣 1 分，
   同时压上**半透明模糊遮罩**锁住作答区，只能点「恢复全屏继续考试」重新进入全屏后才能继续作答；
   刷新恢复会话时若浏览器因缺少用户手势拒绝全屏，也会显示同一遮罩让学生补一次手势。
6. 断线、关浏览器、换电脑都没关系 —— 重新填**同一个姓名**就会回到自己那套环境
   （沙箱状态、进度、时间都在 `data/exam.db` 里按姓名归并）。

## 四、与完整版的主要差异

| 维度 | 完整版 D:\KSXT | 简化版 |
| --- | --- | --- |
| 命令在哪跑 | QEMU 虚拟机 + SSH PTY + xterm.js | 进程内 `LinuxSim` 沙箱，页面只有输入框 + 滚动区 |
| 进入前等待 | 分配虚拟机、开机自检数分钟 | 无，名字提交即刻进 |
| 作答顺序 | 按题号推进，需要 `selected` 游标 | **完全乱序**，一回车遍历全部未通过题 |
| 防误亮 | 顺序天然形成依赖 | 每题额外声明 `need`（命令名归属）+ `after`（因果前置） |
| 题号场景 | 原始剧情人物目录 | 八幕骨架，人物/路径/权限数字/命令组合全部换过一套 |
| 学生端题单 | 按幕分组 | **平铺 37 条，只留题号**（`act` 字段仍在接口里，教师端还按幕管理） |
| 未设置开考时间 | 闸门放行，学生可随时进入并按个人 120 分钟计时 | **闸门关闭**（`not_set`），填姓名被挡在门外，进行中的会话也不能执行命令 |
| `clear` | 真终端擦屏 | 接口新增 `cleared` 标志位，由前端擦屏；判分不受影响 |
| 命令日志 | 含交互续行 | 只记真实命令行（**明文密码不进日志、不回显**） |
| 教师「运行状态」 | 每台 VM 一个节点 | 每份正在作答的沙箱一个节点（id 用姓名，busy = 作答中），字段不变 |

## 五、题库与计分

- 37 题 = 第一幕 3 · 第二幕 6 · 第三幕 7 · 第四幕 5 · 第五幕 3 · 第六幕 5 · 第七幕 2 · 第八幕 6
  （幕只存在于接口与教师端，学生端题单是平铺的 1–37）
- 分值严格按教师规划表逐行录入：5 分题 5 道 + 4 分题 6 道 + 3 分题 3 道 + 2 分题 18 道 + 1 分题 5 道，
  **原始合计 99 分**。成绩按 `已得原始分 ÷ 99 × 100 − 罚分` 归一，所以做满 37 题仍是 **100 分**；
  归一结果**四舍五入取整为整数分**（教师端、学生端、成绩 CSV、排行榜口径一致，不出现小数分数）；
  退出全屏一次扣 1 分（分数下限 0）。
- 判分是**三段式**：命令归属（本轮命令链里要有该题要求的命令）+ 写法（部分题核对参数，如 `-p`、
  `-r -f` 同行、`g+w` 字母法、独立的 `-n`）+ 现场结果（用户表 / 组表 / 文件树 / 权限位 / 当前身份与目录 /
  上一条输出）。三段缺一不得分，逐条实测边界见教师用《题目与答案.md》第五节
  （私有资料，未随公开仓库分发）。
- 37 题里 23 题带 `after` 因果闸，12 题只受 `need` 命令名闸，2 题完全开放。
- 软链接 `ln`、打包 `tar`、改属主 `chown` 按新表移出考范围：命令仍可执行，但不点亮任何题。
- 只用完整版 PPT 命令范围内已实现的命令（`PPT_COMMANDS`，教师端「命令使用统计」按它计数）。

## 六、时间与闸门

配置在 `data/config.json`（`exam_title` / `exam_start` / `exam_minutes` / `exam_closed`），
由教师端「考试设置」页写。闸门四态：`not_set` / `before` / `open` / `closed`。

- **未设置开考时间 → `not_set`**：这场考试还没安排。`/api/exam/start` 返回 403，学生填姓名进不来；
  已经在作答的会话敲命令同样 403（沙箱不判分）。教师在控制台点「立即开始」或设定时间后闸门才放开。
- **`before`**：距开考 **300 秒内**允许提前进入看题但不能执行命令，更早则 403 并带倒计时。
- **`open`**：可作答，到达 `exam_start + exam_minutes` 自动收卷；`exam_closed` 为真时立即结束。
- 学生端登录页与考试页都实时显示闸门状态，未开放时「开始考试」按钮是禁用的。

## 七、⚠️ 姓名即凭证，请务必读

简化版没有账号系统，**姓名就是唯一凭证**，请把它当成口令对待：

- 姓名**完全一致**才能找回自己的环境；中间多一个空格（`李 四` vs `李四`）视为**另一个人**。
  只有首尾空白会被折叠。写错名字按「没考过」处理，会新建一份空环境，原进度不会丢但看不见。
- 反过来，**别人的 sid + 自己的姓名不会串号**（后端强制校验姓名一致），但**知道别人姓名就等于拿到别人环境**。
  所以考试前统一规定姓名的写法，并在同一个入口让学生填。
- 交卷后同名不再复用（`resume` 只认未交卷的会话），重考需要教师端处理记录。
- 教师端 8101 免登录，靠「只监听本机 + 不进隧道」保护 —— **不要把 8101 也开进隧道**。

## 八、自检

```bash
cd 考试系统简化版
python tests/selfcheck.py     # 259 项：进程内判分、乱序、分值表逐行对齐、history 双题不互蹭、交互续行、整数分
python tests/e2e_http.py      # 282 项：真起 8100/8101 打 HTTP，含未排期闸门（not_set 进不来也答不了）、
                              #        姓名找回、重启恢复、教师端全接口、CSV 导出、force_pass、交卷罚分
```

`e2e_http.py` 使用独立数据目录 `data/e2e_tmp/`，不会污染 `data/exam.db`；
测试期间会占用 8199（学生）与 8101（教师）端口，跑真实考试前先关掉测试进程。
